## ⚡ Overview

A high-performance dual-mode portfolio crafted for **Aayush Askandani** (Full-Stack Software Engineer & Systems Builder, Poornima University, Google Cloud Arcade Legend).

Featuring:
1. **Modern Dark Canvas Mode:**
   - ⚡ **Interactive Micro-Simulators:** Live URL hashing latency benchmark (LinkForge) and fractional indexing midpoint calculator (SyncBoard).
   - 🏗️ **Architecture Pipeline Lightboxes:** End-to-end dataflow topologies.
   - 🧲 **Magnetic Button Physics:** Cursor tracking magnetic CTAs.
   - 🎵 **Web Audio Ambient Synthesizer:** Real-time polyphonic ambient soundscapes without external MP3 dependencies.
   - 🔍 **Command Palette (Ctrl+K / ⌘K):** Instant spotlight search and quick navigation.
   - 🎙️ **J.A.R.V.I.S. Tactical HUD & Voice AI:** Holographic system scanner and interactive mock interviewer.

2. **Retro Windows 98 / XP Interactive OS:**
   - Multi-window desktop with draggable, resizable windows, taskbar, start menu, and themes.
   - Native retro applications:
     - `TERMINAL.EXE` — Interactive PowerShell 7 shell with cmdlets.
     - `BUILDER_LAB.EXE` — Deep-dive engineering dossiers and trade-offs.
     - `RECRUITER.TXT` — 60-second executive summary with resume download.
     - `PROOF_GALLERY.EXE` — Verified Google Cloud credentials & GDG achievements.
     - `INTERVIEW_SIM.EXE` — Voice-synthesized mock technical interview.
     - `STORY_MODE.EXE` — 9-chapter developer origin narrative.

## 🛠️ Tech Stack

- **Frontend Core:** React 19, TypeScript, Vite
- **Styling & Motion:** Tailwind CSS, Custom CSS Canvas transforms, Bevel 3D OS shaders
- **Audio Synthesis:** Web Audio API (real-time harmonic synthesizers & procedural SFX)
- **Deployment:** Vercel SPA Routing (`vercel.json`)
- **SEO & Social:** OpenGraph tags, Twitter Cards, Canonical links, `sitemap.xml`, `robots.txt`

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/aayushaskandani/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

---

## 📦 Build for Production

```bash
npm run build
```
